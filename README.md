# Pythonablo

**Pythonablo** — однопользовательская 2D isometric ARPG в духе Diablo, написанная на Python с использованием [Pygame](https://www.pygame.org/). Исследуйте процедурные подземелья, собирайте лут, прокачивайте навыки и сражайтесь с ордами монстров — в классическом режиме или в режимах арены и скорости.

> Полное название в окне игры: **Pythonablo — Diabloid ARPG**

## Возможности

- **Изометрическая карта** с процедурной генерацией комнат и коридоров
- **Ближний бой** — полукруглый удар по направлению к курсору, рывок и удерживаемый «Вихрь» (ПКМ)
- **4 активных умения** — огненный шар, ударная волна, призыв и импульс; каждое можно улучшать
- **Древо пассивных навыков** — 10 характеристик, до 10 рангов в каждой (+1% за ранг)
- **Система лута** — normal / magic / rare / legendary / set с аффиксами и уникальными легендарками
- **Сет «Аркан»** — 5 слотов с бонусами за комплект
- **NPC** — Кузнец (магазин) и Наставник (пассивные навыки)
- **Случайные события этажа** — орда, сокровищники, защита жителя, проклятия и благословения
- **Колонны-пилоны** — случайный бафф или дебафф при взаимодействии
- **4 режима игры** и **3 уровня сложности**
- **Автосохранение** и ручное сохранение из меню паузы
- **Процедурный звук** — SFX и музыка генерируются кодом, внешние аудиофайлы не нужны

## Установка и запуск

```bash
# Клонировать репозиторий
git clone <url-репозитория>
cd Pythonablo

# Создать виртуальное окружение (рекомендуется)
python -m venv venv

# Windows
venv\Scripts\activate

# Linux / macOS
source venv/bin/activate

# Установить зависимости
pip install -r requirements.txt

# Запустить игру
python main.py
```

При первом запуске игра создаёт папку `save_data/` для сохранений и при необходимости копирует спрайты в `assets/` (см. [Графика и звук](#графика-и-звук)).

## Управление

### Движение и бой

| Действие | Клавиша / кнопка |
|----------|------------------|
| Движение | `W` `A` `S` `D` или стрелки |
| Атака (направление — к курсору) | ЛКМ (удержание — серия ударов) |
| Вихрь (удержание) | ПКМ |
| Рывок | `Space` |
| Огненный шар | `1` или `F` |
| Ударная волна (AoE) | `2` |
| Призыв миньонов | `3` |
| Импульс | `4` |

### Интерфейс

| Действие | Клавиша |
|----------|---------|
| Инвентарь | `I` |
| Взаимодействие (NPC, портал, предмет, колонна) | `E` |
| Пауза | `Esc` |
| Подтверждение в меню | `Enter` |
| Навигация в меню | стрелки / `W` `S` |
| Смена сложности в главном меню | `←` `→` |

### Инвентарь (мышь)

- **ЛКМ** по предмету в рюкзаке — экипировать в подходящий слот
- **ЛКМ** по экипированному предмету — снять в рюкзак
- **ПКМ** по предмету — распылить (получить пыль для магазина)
- Кнопка «Распылить всё» — массовое распыление

## Режимы игры

| Режим | Описание |
|-------|----------|
| **Классика** | Подземелья с этажами, лут, NPC, порталы вниз/вверх, боссы каждые 3 этажа |
| **Арена** | Выживание: каждые **30 секунд** — новый раунд с усиленными врагами |
| **Арена с боссами** | Как арена, но все враги — боссы |
| **Скорость** | Скорость игры **×2**, с врагов падают только временные бонусы (автоподбор) |

В режиме **Классика** на каждом этаже (кроме первого) может выпасть одно случайное **событие этажа**. Каждый 3-й этаж — **босс-этаж** с особой музыкой и усиленными противниками.

---

## Сложность

В главном меню стрелками `←` / `→` выбирается сложность:

| Сложность | Эффект (относительно «Средний») |
|-----------|----------------------------------|
| **Лёгкий** | +35% HP игрока, +15% урон; −28% HP врагов, −35% урон, −15% количество |
| **Средний** | Базовый баланс |
| **Сложный** | −12% HP, −8% урон игрока; +40% HP врагов, +35% урон, +20% количество |

## Геймплей

### Классический режим

1. Стартуете на **этаже 1** в процедурно сгенерированном подземелье.
2. Уничтожаете врагов, подбираете лут и бонусы.
3. Подходите к **порталу выхода** (`E`) — переход на следующий этаж.
4. На этажах **> 1** есть **лестница вверх** — возврат на предыдущий этаж (состояние этажей кэшируется).
5. Каждые **3 этажа** — босс-этаж; на этаже **до босса** (`floor % 3 == 2`) появляется **Кузнец**.

### Арена

- Таймер **30 секунд** на раунд; после истечения — новая волна и рост множителя сложности (+15% за раунд).
- Цель — продержаться как можно дольше.

### Ресурсы

- **HP** — регенерирует со временем; восстанавливается зельями и некоторыми эффектами.
- **Мана** — тратится на умения; восстанавливается пассивно.
- **Золото** — с убийств и продажи; покупки у Кузнеца.
- **Пыль** — распыление предметов; валюта магазина за редкий лут.

## Системы прогрессии

### Уровни

- Опыт дают убитые враги; формула роста XP к следующему уровню: `XP × 1.18 + 4`.
- При повышении уровня растут базовые статы и выдаётся **1 очко пассивного навыка**.
- Каждые **5 уровней** — **1 очко улучшения активного умения**.

### Пассивные навыки (Наставник)

Наставник появляется на этаже каждые **2–4 этажа**. У него открывается экран с 10 слотами:

| Характеристика | Эффект за ранг |
|----------------|----------------|
| Макс. HP / мана | +1% |
| Урон атаки / броня / реген | +1% |
| Урон умений / скорость бега | +1% |
| Скорость атаки / реген маны | +1% |
| Крит. урон | +1% (учитывается в множителе урона) |

Максимум **10 рангов** на слот.

### Улучшения активных умений

| Умение | Эффект за уровень |
|--------|-------------------|
| Ударная волна | Радиус ×2 |
| Огненный шар | Размер снаряда +40% |
| Вихрь | Красный вихрь, +15% урона |
| Импульс | Радиус +30% |
| Призыв | +1 миньон, +20% HP миньонов |

## Лут и экипировка

### Качество предметов

| Качество | Цвет | Особенности |
|----------|------|-------------|
| Normal | Серый | Базовые статы |
| Magic | Синий | 1–2 случайных аффикса |
| Rare | Жёлтый | 3–4 аффикса |
| Legendary | Оранжевый | Уникальный аффикс или замена умения |
| Set | Бирюзовый | Часть сета «Аркан» |

### Слоты экипировки

Шлем, наплечники, кираса, перчатки, пояс, штаны, сапоги, амулет, 2 кольца, тalisman, основное и дополнительное оружие, а также **5 слотов сета**.

### Легендарные предметы

Легендарки делятся на:

- **Статовые** — вампиризм, шипы, удача, ярость, сердце феникса (одно воскрешение) и др.
- **Трансформации вихря** — огненный / ледяной / ядовитый (перчатки, обод, кольцо).
- **Замена умения** — легендарка в слоте заменяет одно из умений `2`, `3` или `4` на уникальную способность (метеориты, цепная молния, проклятие, щит маны и т.д.).
- **Самонаводящаяся стрела** — заменяет обычную атаку ЛКМ.

Полный список — в `core/legendary_defs.py`.

### Кузнец

На этаже перед боссом доступен **Кузнец** (`E` рядом с NPC):

- **Магазин** — предметы за пыль и золото
- **Улучшение** — повышение редкости экипировки
- **Перекат** — новая генерация аффиксов

## NPC и события

### NPC

| Персонаж | Когда появляется | Действие |
|----------|------------------|----------|
| **Кузнец** | Этаж `(floor % 3) == 2` | Магазин и услуги |
| **Наставник** | Каждые 2–4 этажа | Древо пассивных навыков |

### События этажа (Классика)

- **Защитите жителя!** — NPC с HP; нужно удержать его живым
- **Убейте всех — элита!** — после зачистки появляется элитный враг
- **Сокровищники** — особые враги с повышенным лутом
- **Проклятие / благословение этажа** — временный дебафф или бафф
- **Орда** — втрое больше врагов на этаже

### Колонны

На этажах стоят **колонны** — при нажатии `E` рядом срабатывает случайный эффект: исцеление, мана, сила, слабость, замедление и др.

### Временные бонусы с врагов

С шансом **12%** (в режиме Скорость — **100%**) выпадают подбираемые сферы: взрыв, броня, скорость, урон, аура боли, усиление умений.

## Сохранения

- Файл: `save_data/save.json`
- **Автосохранение** каждые **5 убийств**
- **Ручное сохранение** — пауза → «Сохранить»
- Сохраняются: этаж, режим, сложность, статы игрока, инвентарь, экипировка, навыки, состояние посещённых этажей, прогресс арены
- В главном меню пункт **«Продолжить»** появляется, если сохранение существует

## Структура проекта

```
Pythonablo/
├── main.py                 # Точка входа
├── requirements.txt
├── assets/                 # Спрайты и фон (см. ниже)
├── data/                   # JSON-шаблоны предметов, врагов, навыков
│   ├── items.json
│   ├── enemies.json
│   └── skills.json
├── save_data/              # Сохранения (создаётся автоматически)
├── core/                   # Конфиг, игровой цикл, события, легендарки
│   ├── config.py           # Константы, режимы, сложность
│   ├── game.py             # Главный цикл и машина состояний
│   ├── event_bus.py
│   └── legendary_defs.py
├── engine/                 # Рендер, ввод, камера, аудио, спрайты
├── entities/               # Игрок, враги, NPC, предметы, снаряды
├── player/                 # Статы, инвентарь, экипировка, навыки
├── systems/                # Бой, AI, лут, умения, эффекты, события
├── ui/                     # Меню, HUD, инвентарь, магазин, пауза
├── world/                  # Карта, генерация, коллизии, pathfinding
└── save/                   # SaveManager, состояние этажей
```

### Архитектура

- **`Game`** (`core/game.py`) — центральный класс: Pygame-цикл, переключение `GameState`, координация систем.
- **`EventBus`** — pub/sub для событий (`enemy_killed`, `player_died`, `skill_cast` и др.).
- **Системы** (`systems/`) — изолированная логика боя, AI, лута, бонусов, умений.
- **Данные** — шаблоны в `data/*.json`; баланс и константы в `core/config.py`.

## Графика и звук

### Спрайты (`assets/`)

Игра загружает PNG/JPG из папки `assets/`. Ожидаемые файлы:

| Файл | Назначение |
|------|------------|
| `player.png` | Спрайт игрока |
| `enemy_normal.png`, `enemy_tank.png` | Обычные и «танковые» враги |
| `demon.png`, `zombie.png`, `ghost.png`, `ghost2.png`, … | Уникальные враги (см. `data/enemies.json`) |
| `npc1.png`, `npc2.png`, `npc3.png` | Кузнец, Наставник, житель |
| `column.png` | Колонна-пилон |
| `fire.png`, `whirlwind.png`, `b.png`, `item.png` | Иконки умений и UI |
| `background.jpg` | Фон (опционально) |
| `logo.png` | Логотип в меню (опционально) |

При первом запуске, если `assets/` пуста, игра **пытается скопировать** спрайты из соседнего проекта `Python Survivors` (путь захардкожен в `core/game.py`). Если копирование недоступно — положите файлы в `assets/` вручную; игра запустится и без них, но с упрощённой отрисовкой.

### Звук

Звуковые эффекты и музыка **генерируются процедурно** в `engine/audio.py` (синусоиды и шум через `pygame.mixer`). Отдельные аудиофайлы не требуются.

## Быстрый старт для разработчиков

```bash
pip install -r requirements.txt
python main.py
```

Полезные точки входа для изменений:

- **Новый враг** — запись в `data/enemies.json` + спрайт в `assets/`
- **Новый предмет** — `data/items.json` или генерация в `systems/loot_system.py`
- **Новое легендарное умение** — `core/legendary_defs.py` + `systems/legendary_skills.py`
- **Баланс** — `core/config.py`

Удачи в подземельях!
